## Ключевые проекты

### 1. Мультиагентная платформа для генерации прозы (2025–2026)
Спроектировал архитектуру и собрал платформу, где 5 AI-агентов (писатель, канон, стилист, секретутка, менеджер) совместно пишут и проверяют главы художественных текстов. Пайплайн включает RAG, tool calling, SSE-стриминг и распределённую инфраструктуру.

- **Контекстное окно:** скользящее окно из 5-6 последних глав + 4-5 RAW-дискуссий + суммаризация остального чата. Решает проблему деградации контекста на длинных дистанциях
- **Tool calling:** 4 инструмента (ws_read, ws_write, ws_list, journal_append) — агенты реально создают файлы на диске, а не имитируют работу
- **Персональные правила:** у каждого агента — собственная personal_rules.md, а не общая «память»
- **4 слоя данных:** Personal Rules (рабочие привычки), Project Journal (лог), Canon (мир), Experience (уроки)

### 2. Роман на 28 глав — AI без ручного редактирования (2025)
Спроектировал пайплайн генерации, который выдал законченный роман в жанре contemporary romance (28 глав) без единой правки текста человеком. Доступен под псевдонимом Арон Родович.

- Deep prompt engineering для консистентного голоса персонажа на всём протяжении романа
- Pipeline проверок: писатель → канон → стилист → секретутка
- Chistovik — автоматическая чистка AI-маркеров, «воды», повторов, клише
- **Вывод:** заставить AI писать хорошую прозу **сложнее**, чем хороший код — нет тестов, которые отловят потерю голоса персонажа в 20-й главе

### 3. Методология AI-письма (2025–2026)
Разработал стандарты и инструменты для производства художественных текстов через AI.
